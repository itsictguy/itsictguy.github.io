Elyon Attendance System

Aplikasi HRD untuk tracking kehadiran karyawan dengan fitur lengkap seperti employee management, calendar views, approval workflows, dan role-based access control.

Key Features:

  • Real-time attendance tracking dengan calendar integration
  • Holiday management dengan API integration
  • Approval system untuk late arrivals dan absences
  • Excel export functionality untuk reporting
  • Role-based access control menggunakan Spatie Laravel Permission

Teknologi yang digunakan

Laravel 12 React TypeScript Inertia.js MySQL
